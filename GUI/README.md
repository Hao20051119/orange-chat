# Orange 桌面控制台预览

双击 `启动 Orange.bat`，也可以用已安装工程依赖的 Python 运行 `GUI/app.py`。如旧版后台正在运行，先用原来的停止脚本关闭，再启动预览。使用与微信相同的 Windows 用户运行。

如果启动失败，窗口会提示原因。Python 层的启动错误会写入 `GUI/.runtime/startup.log`。

1. 登录微信，保持主窗口可用。在 Orange 里刷新账号列表，选中要绑定的小号并确认身份。列表只显示能核验数据目录和登录窗口的账号。微信不提供主号或小号标签，请自行确认账号。
2. 选择已配置的模型 API，或输入兼容 OpenAI Chat Completions 的 API 地址、模型 ID 和密钥。点击「测试模型 API」会向所选接口发送一条固定测试消息。自定义密钥填写后会保存在本机 `%USERPROFILE%\.orange\api_keys.json`（不入库、不随迁移包走），可在下拉框中复用或删除。本机回环模型可以留空密钥。
3. 点击「连接并启动」，在概览核对账号和模型。自动回复、主动聊天和提醒每次启动时都处于关闭状态，可在对应页面打开。开启自动功能前，可在会话页设置黑名单、在设置页配置回复范围。

控制台包含概览、固定人设、关系、会话与发送、黑名单与接管、待处理、定时提醒、主动聊天、知识库、日志与用量和设置。点「停止并更换账号」后可重新选择账号或模型。手动发送与自动发送都需要核验实际目标。系统无法确认送达时会提示未核实。

- 概览：未处理、重试、排队待发、待审核、已发送、失败、待核验、暂停中共 8 项指标。
- 固定人设：直接编辑提示词最前面的那段人设，10～4000 字，保存后下一句回复生效，不用重启。数据存在 `persona_card.json` 的 `fixed_persona`。
- 关系：家人/共同认识的人以及每个联系人是谁（称呼、关系、你对对方的称呼、绑定会话、备注）。关系表随每轮对话写入提示词，不依赖记忆摘要；`绑定会话` 从会话列表下拉选联系人（显示为「显示名 · wxid」），选「不绑定」表示双方共同认识、并不直接对话的人（如对方家人）。
- 黑名单与接管：集中查看和编辑黑名单、暂停中的会话，支持手动拉黑/移出、手动暂停/恢复。
- 待处理：正文可直接编辑，「保存修改」只改不发送，「批准发送」会用改好的正文。

固定人设与关系的详细设计见仓库根目录 `README.md` 的「配置要点」一节。

预览使用 `GUI/.runtime/` 下的账号独立配置和数据库。旧版的队列、记忆、知识库三个库已合并进预览会话；之后如需再次同步，运行 `python.exe tools\migrate_gui_data.py`（默认只报告，加 `--apply` 才写库，写前自动备份）。旧版控制台与网页的入口继续使用原来的启动方式。

## 界面外观

窗口是米色底 + 圆角渐变毛玻璃卡片，按钮/下拉框/输入框/勾选框/表格都是胶囊或圆角样式。Tk 本身不支持圆角、渐变和模糊，这些外观由 `GUI/ui.py` 用 Pillow 渲染成 2 倍超采样图片（按尺寸和状态缓存），Tk 只负责布局和事件。缺 Pillow 时（Pillow 由 `wechatauto-replica` 依赖带入，也可 `pip install pillow` 单独装）自动退回方块样式，功能不受影响。

字号随窗口大小自动缩放：以 1180 宽为 1.0 倍，窗口越大字号和控件越大，最大 1.4 倍（全屏时不会显得字很小）。改完窗口尺寸会在拖动结束后重排一次当前页；缩放系数由 `app.py` 的 `ui_scale()` 决定，想更激进就调 `BASE_WIDTH` 或那个 1.4 的上限。

- 改配色：`GUI/app.py` 顶部的 `BG / CARD / INK / MUTED / LINE / ORANGE` 与 `PAL = Palette(...)`。
- 改圆角、描边、阴影：`GUI/ui.py` 里的 `render_card / render_button / render_well / render_check`。
- 改单个控件：按钮 `PillButton`、下拉 `PillSelect`、输入框 `EntryField`、多行文本 `GlassText`、卡片 `GlassFrame`、勾选框 `PillCheck`。
- 开发期看外观：`python tools\smoke_gui_pages.py`（无头构建全部页面，抓 Tk 回调异常）。
